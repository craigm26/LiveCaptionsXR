🏪 Option 1: Google Play Store

The simplest path — install like any other app.

  1. Open the Google Play Store on your Android XR headset
  2. Search for "LiveCaptionsXR"
  3. Tap Install
  4. Grant permissions when prompted:
    Microphone — required for speech capture
    Camera — optional, enables speaker localization & visual context
  5. Launch the app — models will download on first run (~200–500 MB over WiFi)
  6. Point your headset toward a speaker and captions appear in your field of view

⚡ Option 2: Sideload APK (Nexa AI / NPU)

For Qualcomm Snapdragon devices that can leverage the dedicated neural processor.

Supported NPU Devices Samsung Galaxy XR (Snapdragon 8 Elite) · Qualcomm QRD8750 / QRD8650 reference boards · Any Snapdragon 8-series (2022+) with Hexagon NPU

Method A: Sideload via ADB (developers)

# Connect your headset via USB or wireless ADB
adb devices

# Install the APK
adb install app-release.apk

# Upgrading from a previous version?
adb install -r app-release.apk

# Launch
adb shell am start -n com.livecaptionsxr.app/.MainActivity

Method B: Sideload without a computer

  1. On your headset, go to Settings → Security → Install unknown apps
  2. Enable installation from your browser (Chrome, etc.)
  3. Open the GitHub Releases page in the headset's browser
  4. Download the app-release.apk file
  5. Tap the downloaded APK to install
  6. Grant permissions (Microphone, Camera) when prompted

Method C: Qualcomm Device Cloud (QDC)

# Upload APK to your QDC session
adb -s <device-serial> install app-release.apk

# Verify installation
adb shell pm list packages | grep livecaptionsxr

# Verify NPU detection in logs
adb logcat -s NexaAsrPlugin | grep "NPU"
# Expected: "NPU availability check: chipset=qcom, hardware=qcom, supported=true"

🚀 First Launch — What to Expect

  1. Permission prompts — Allow microphone (required) and camera (recommended for speaker localization)
  2. Model download — AI models download once over WiFi (~200–500 MB). This is a one-time setup.
  3. Hardware detection — The app auto-detects your chipset and selects the optimal AI pipeline. You'll see a brief loading indicator.
  4. Ready — Point toward a speaker. Captions appear in your field of view, spatially anchored near the speaker's position.

Troubleshooting

App crashes on launch (sideloaded version)

Ensure your device has a Qualcomm Snapdragon 8-series chipset. Check logcat for the specific error:

adb logcat *:E | grep livecaptionsxr

Try clearing app data: Settings → Apps → LiveCaptionsXR → Clear Data

If using v1.0.20 or earlier, upgrade to v1.0.22+ which fixes the Nexa SDK initialization crash.

NPU not detected on a supported device

Some reference boards report non-standard chipset names. We support QRD board IDs and Qualcomm internal codenames (pineapple, kalama, waipio, taro).

Check what your device reports:

adb shell getprop ro.board.platform
adb shell cat /proc/cpuinfo | grep Hardware

If your device isn't detected, file an issue on GitHub with the output above.

Models won't download

Models need ~1 GB free storage and a WiFi connection (200–500 MB download).

On QDC sessions, WiFi may need to be enabled manually:

adb shell svc wifi enable
Captions are delayed or laggy

Close other resource-heavy apps. The sideloaded Nexa NPU version has significantly lower latency than the CPU-based Whisper path — consider sideloading if you're on a supported Snapdragon device.

Ensure the headset isn't in power-saving mode, which throttles the CPU/NPU.
