# Gemma 3n Streaming Head

- Place quantized `.task` bundles (e.g., `gemma3n_predictive_int8.task`) in this directory.
- Update `pubspec.yaml` assets section if bundling the model with the app, or provide a download path via `ModelDownloadManager`.
- Calibration artifacts for Gemma should accompany the model under `assets/spatial_intel/calibration/`.
