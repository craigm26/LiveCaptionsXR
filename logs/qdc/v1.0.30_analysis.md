## Root Cause: ASR Create Failure — WRONG model_name!

The Nexa SDK `AsrCreateInput.model_name` is NOT the model ID from `model_list.json`.
It's a **short internal name** that the NPU plugin uses to find the right model graph.

**Nexa docs example:**
```kotlin
AsrCreateInput(
    model_name = "parakeet",  // SHORT name, not full ID
    model_path = <folder-path>,
    plugin_id = "npu"
)
```

**What we're sending:**
```
model_name = parakeet-tdt-0.6b-v3-npu   ← WRONG (full download ID)
model_path = .../files/models/parakeet-tdt-0.6b-v3-npu
plugin_id = npu
[JNI] ml_asr_create failed, error code: -100001
```

The NPU plugin looks up `model_name` in an internal registry of model graphs.
`"parakeet"` is a valid graph name. `"parakeet-tdt-0.6b-v3-npu"` is not.

**Error -100001** = model name not found in NPU plugin's model registry
**Error -100013** = model file not found at path (CPU fallback using wrong path)
